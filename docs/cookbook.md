# Cookbook notebooks

The [laiser-cookbook](https://github.com/LAiSER-Software/laiser-cookbook) repository holds complete
analyses built on LAiSER. Each opens directly in Google Colab, which is the quickest way to try the package
without a local install.

!!! tip "Running in Colab"
    The notebooks use a hosted model, so add your provider key as a Colab secret (the key icon in the
    left sidebar) before running. To avoid needing a key, switch the extractor to a small local model as
    shown in the [Quickstart](quickstart.md) — expect slower extraction on Colab's CPU runtime.
